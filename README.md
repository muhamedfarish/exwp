## 🚀 Quick Start

> ⚠️ Prerequisite: Latest Docker & Docker Compose must be installed, Otherwise you will face errors while installing.

### 🔧 Run the Lab

```bash
git clone https://github.com/muhamedfarish/exwp.git
cd exwp
docker-compose up -d
```

Visit the web:
http://localhost:8111
Admin Panel Credentials:
admin:expwp@9870
